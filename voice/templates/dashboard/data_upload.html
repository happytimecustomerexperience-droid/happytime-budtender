How this works

  1. Download the template (or export what is there now) and open it in Excel or Google Sheets. The two example rows are switched off; replace or delete them.
  2. Rows are matched on {% for k in ds.key_fields %}{{ k }}{% if not forloop.last %} + {% endif %}{% endfor %}: a match updates that row, anything else is added. Rows missing from your file are never deleted.
  3. To delete a row, put yes in its delete cell and tick "Allow deletes".
  4. A blank cell clears a text or date field. For yes/no and number fields a blank cell keeps the current value (or the default for a new row). A column you leave out is not touched.
  5. Save as CSV (UTF-8 is best; UTF-16 and Windows-1252 also work). Up to 1 MB and {{ max_rows }} rows.
  6. Text that starts with = or @ (or +/- when it is not a plain number) is refused, because a spreadsheet would run it as a formula. Put an apostrophe in front ('-10% off) if it really is text. Downloads add that apostrophe for you and it is removed again on upload.
  7. Press Apply on the preview. Everything valid is saved together in one step.
